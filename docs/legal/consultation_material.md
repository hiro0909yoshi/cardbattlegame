# 法律相談資料 — Arcana Conquest

## 1. アプリ概要

| 項目 | 内容 |
|------|------|
| アプリ名 | Arcana Conquest（アルカナコンクエスト） |
| ジャンル | カードバトル＋ボードゲーム（カルドセプト風） |
| 開発者 | 個人開発 |
| エンジン | Godot Engine 4.5（オープンソース） |
| プラットフォーム | iOS / Android |
| 価格 | 無料（アプリ内課金あり） |
| 開発段階 | 開発中（リリース前） |

## 2. ゲームシステム

- 周回型ボード上をダイスで移動
- マスにクリーチャー（カード）を配置し、土地を支配
- 他プレイヤーの土地に止まると通行料が発生
- カードバトルで土地の奪い合い
- 先にEP（勝利ポイント）を貯めたプレイヤーが勝利

**着想元**: 「カルドセプト」（大宮ソフト/任天堂）
- ゲームシステム（ボード移動→土地配置→通行料→バトル）が類似
- カード名・キャラクター名・画像は全てオリジナル
- UI・演出も独自に設計

## 3. 課金システム

### 3-1. ゲーム内通貨

| 通貨 | 入手方法 | 用途 |
|------|---------|------|
| ゴールド | ゲームプレイ報酬 | ゴールドガチャ |
| ジェム | App Store / Google Play で購入 | 課金ガチャ |

- ジェムは現金に換金不可
- アプリ内でのみ使用可能
- 決済はApple/Googleのシステムを経由（開発者がカード情報を扱わない）

### 3-2. ガチャシステム

**ゴールドガチャ（ゲーム内通貨）**:

| タイプ | 1回 | 10連 | 100連 | 排出レアリティ |
|--------|-----|------|-------|-------------|
| ノーマル | 50G | 500G | 5,000G | C: 60% / N: 40% |
| Sガチャ | 80G | 800G | 8,000G | C: 50% / N: 35% / S: 15% |
| Rガチャ | 100G | 1,000G | 10,000G | C: 50% / N: 35% / S: 12% / R: 3% |

**課金ガチャ（ジェム）**:

| 回数 | 価格 | 排出レアリティ |
|------|------|-------------|
| 1回 | 100石 | S: 70% / R: 30% |
| 10連 | 900石 | S: 70% / R: 30% |

- 7タイプ（火/水/地/風/無属性 + スペル + アイテム）から選択
- 各タイプ内で該当カードが均等確率で排出
- 排出確率はアプリ内「提供割合」ボタンで常時確認可能
- 合成・変身専用カード（3種）はガチャから排出されない

### 3-3. コレクションコンプリート演出

- 各属性のカードを全種類揃えるとお祝いポップアップが表示される
- **コンプリートによる追加報酬（レアカード等）は一切なし**
- 演出のみで、ガチャを促進する仕組みではない
